# 贪吃蛇小游戏 — 设计文档

- **日期**：2026-08-08
- **分支**：`snake-game`（与主线 `master` 完全隔离开发）
- **状态**：方案已确认，待实现

## 一、目标

在「天天记账」App 内新增一个**贪吃蛇小游戏**，作为记账之余的休闲小功能。
游戏是独立玩法，**不涉及任何记账数据**，与账本功能完全隔离。

## 二、需求（用户已逐条确认）

| 项目 | 决定 | 说明 |
|---|---|---|
| 入口 | 左侧导航**第 5 页「小游戏」** | 与概览/账单/统计/设置平级 |
| 操作 | 键盘方向键 **↑ ↓ ← →** | 转向，不能 180° 掉头撞自己 |
| 难度 | **固定速度**（每 150 毫秒动一格） | 不快不慢 |
| 成绩 | **显示本次分数 + 保存历史最高分** | 最高分下次打开还在 |
| 最高分存放 | **单独小文件** `snake_highscore.json` | 存在系统用户数据文件夹，**不碰账本数据库** |
| 画法 | **HTML5 Canvas 画布** | 游戏标准做法，流畅 |
| 音效 | **有**：吃到食物「叮」声、游戏结束一声 | 用程序自带的"电子发声"（Web Audio API），**不下载任何资源** |

## 四、游戏机制

1. **棋盘**：20×20 格，画布 400×400（每格 20 像素）。背景画浅色格线，方便看清。
2. **蛇**：初始在棋盘中央，长度 3 节，初始方向向右。蛇身绿色（头部略深），与 App 主色调呼应。
3. **食物**：每次随机生成一个红色小方块，**保证不在蛇身上**。
4. **移动**：固定每 150ms 移动一格。按方向键转向，**每 tick 应用一次方向**；禁止直接反向（如向右时不能直接按左）。
5. **吃**：头碰到食物 → 蛇长 1 节、分数 +1、播放"叮"声、重新生成食物。
6. **结束条件**：
   - 撞墙（走出棋盘）→ 结束；
   - 撞到自己身体 → 结束；
   - 棋盘被填满 → 胜利，也结束（恭喜）。
7. **暂停/继续**：游戏中按**空格键**暂停/继续。
8. **开始/重开**：点「开始游戏」按钮或按**回车**。结束后同样方式再来一局。
9. **最高分**：结束后若本次分数 > 已存最高分，则更新保存。页面顶部始终显示当前最高分。

## 五、技术实现

### 改动文件清单

| 文件 | 改动内容 |
|---|---|
| `src/index.html` | ① 左侧导航新增第 5 项「小游戏」（含 SVG 图标，`data-page="game"`）；② 新增 `<section id="page-game">` 游戏页面（分数区、画布、开始按钮、操作提示） |
| `src/renderer.js` | 新增贪吃蛇游戏逻辑：画布渲染、蛇/食物状态、方向输入、tick 循环、计分、暂停、结束、最高分读写调用、音效 |
| `src/styles.css` | 新增游戏页样式：卡片、分数显示、画布、按钮、提示文字，绿色风格与现有主题一致 |
| `main.js` | 新增两个 IPC 服务：`game:getHighScore`（读最高分）、`game:setHighScore`（写最高分），读写 `app.getPath('userData')/snake_highscore.json` |
| `preload.js` | 新增两个安全接口：`getHighScore()`、`setHighScore(score)` |

### 最高分存取（唯一动"后台"的地方）

- 文件路径：`app.getPath('userData')/snake_highscore.json`，内容是 `{"highScore": 数字}`。
- 读取：文件不存在或解析失败时返回 `0`（游戏照常玩，不报错）。
- 写入：写失败时静默忽略（游戏不受影响）。
- 与账本数据库（`tiantian.db`）**完全独立**，互不读写。

### 游戏逻辑要点（renderer.js）

- 蛇用数组存每节坐标 `[{x, y}, ...]`，头在数组首端。
- 移动 = 新头压入数组首端 + 尾端弹出（吃到食物时不弹出尾端 = 变长）。
- 方向用一个"待用方向"变量，tick 时先判断不是反向再应用。
- 用 `setInterval` 驱动 tick（固定速度）；暂停 = 清掉定时器，继续 = 重新启动。
- 画布绘制：每次 tick 清空 → 画格线 → 画食物 → 画蛇（头部颜色深一档）。
- 键盘事件只在小游戏页**可见/激活**时生效，其他页面按方向键不误触游戏。

### 音效（Web Audio API 自生成，零下载）

- 吃食物：一个短促的高频"叮"声（振荡器 O 形波，约 800Hz，0.1 秒）。
- 游戏结束：一个低沉短音（约 200Hz，0.3 秒）。
- 用 `AudioContext` 临时生成，不加载任何外部音频文件，符合项目"完全离线、不下载任何东西"的既有约束。

## 六、边界情况

| 情况 | 处理 |
|---|---|
| 最高分文件损坏/读不出 | 当 0 处理，游戏正常玩 |
| 最高分文件写失败 | 静默忽略，游戏不受影响 |
| 食物生成位置 | 保证不与蛇身重叠 |
| 棋盘填满 | 判定为胜利，显示恭喜并结束 |
| 快速连按方向键 | 只记录最后按下的合法方向，防穿墙/反穿 |
| 非游戏页按方向键 | 不触发游戏（仅 game 页激活时监听） |
| 窗口缩放 | 画布用固定像素，居中显示，不随窗口缩放变形 |

## 七、测试

1. **手动玩测**：启动 App → 点「小游戏」→ 开始 → 用方向键玩几局，确认：转向、吃食物变长加分、撞墙/撞自己结束、空格暂停、结束后最高分正确保存。
2. **持久化测**：玩出高分后关闭 App 再打开，确认历史最高分还在。
3. **隔离测**：进「小游戏」页之外的其他页面按方向键，确认页面不跳动、游戏不动。
4. **回归测**：记账功能不受影响（记一笔、账单、统计、导出 CSV 照常）。
